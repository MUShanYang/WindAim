# WindAim

<img width="1280" height="960" alt="fc3f4ad4be6ff17188110bc712f2f422_720" src="https://github.com/user-attachments/assets/fdd9a335-129e-4857-a4ab-b193c81b2a42" />

爱来自Grok4.6

丢进 `%APPDATA%\scripts` 就行，Iridium 1.20.1。Combat 里开 WindAim。

BBB

三种瞄法：

- **WindMouse** — 弯着过去，别瞬锁
- **Lock** — 跟死碰撞箱，带点平滑
- **Dynamic** — 不抢准星，只改你鼠标快慢：对着箱子加速，打上了减速

瞄的是箱子上离眼睛最近的点，别老瞄头打不着。按住攻击才动（Hold Attack 可关）。

剩下自己翻设置。Speed 1–90，Range、FOV、轴、隔墙、预测箱子那些都有。Tools 不选就随便什么都能瞄，选了就只认剑镐铲斧锄。

路径那套抄的 [WindMouse](https://github.com/AsfhtgkDavid/windmouse)，原作者 [Ben Land](https://ben.land/post/2021/04/25/windmouse-human-mouse-movement/)，GPLv3。
